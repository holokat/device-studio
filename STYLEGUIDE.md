# Model studio

Use the full browser width for the viewport. Place the inspector in an overlay so toggling controls preserves the camera composition. Below 1100 px the inspector starts closed. Place the collapsible 152 px Views rail on the left below the model title. It starts collapsed on narrow or short windows. Each thumbnail is a render of the same model.

Use the platform system sans serif in its default design. Headings use medium weight, tight tracking and sentence case. Use system monospace for the assembly percentage. The heading scales from 29 to 47 px on desktop. Control labels are 12 to 14 px.

The working chrome uses charcoal #191a1a and #202121, separators #3b3c3c, primary text #f6f4f0, muted text #aaa9a7 and peach #ffae83 for selection and playback. The stage uses warm stone, porcelain or graphite. Burgundy, copper and the optical coating hues come from the supplied phone references. Keep interface accents distinct from model materials.

Use the installed Central outlined icon set at a 1.5 stroke. Use 5 to 8 px radii on controls and 11 px on the inspector. Group section controls at 8 to 14 px and use larger spacing between sections. Use surface changes and fine borders for separation. Keep the viewport free of decorative effects.

The motion controls draw on the direct playback and compact controls in the Brick reference. Use brief state transitions and disable decorative entrance motion when reduced motion is requested. The dark studio shell follows the restrained contrast of the Basement reference. Use the system font specified for this Mac workspace. The Fontastic gallery returned a usage-limit response during implementation.

- [Brick on 60fps](https://60fps.design/apps/brick)
- [Basement on Dark.design](https://www.dark.design/site/basement-1786786858853)

The Perspectives list starts with Free orbit and Display, followed by the twelve reference framings. Keep only phones in the frame. Hardware close-ups and the interior have their own shelf. Use real studio renders for thumbnails. Keep the main viewport full width and use a centered 4∶3 frame for Device wall.
